# Brand assets

`entire-symbol-icon.svg` is Entire's official symbol, the small-size icon variant, copied
unchanged from `entire-brand-kit/symbol/entire-symbol-dark-icon.svg` in the Entire brand kit
(<https://entire.com/downloads/entire-brand-kit.zip>), downloaded 2026-10-30.

The Entire name and logo are Entire's trademarks. They are used here, unmodified, only to
identify the integration. Entirely is an unofficial extension and is not affiliated with or
endorsed by Entire.

The file is the source of `images/entirely-view.svg`, the icon the detail panel's tab
carries. It is not packaged in the VSIX.
