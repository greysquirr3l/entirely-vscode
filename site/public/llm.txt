# Entirely

> An unofficial Visual Studio Code extension for Entire, the Git forge built for agent-human collaboration. It shows Entire's agent sessions, checkpoints and trails inside the editor. The Entire CLI is the source of truth; the extension reads its JSON output and shells out for anything that changes state.

Entirely is a community project and is not affiliated with or endorsed by Entire. It targets Entire CLI 0.12.2. Source: https://github.com/greysquirr3l/entirely-vscode

## Guides
- [Sessions and checkpoints](https://greysquirr3l.github.io/entirely/guides/sessions-and-checkpoints/): Watch live sessions and open checkpoints as diffs.
- [Trails and review](https://greysquirr3l.github.io/entirely/guides/trails-and-review/): Read, approve, comment on and merge Entire trails.
- [Search](https://greysquirr3l.github.io/entirely/guides/search/): Search past agent work, commits and code.
- [Activity, dispatch and recap](https://greysquirr3l.github.io/entirely/guides/activity-dispatch-recap/): Recent activity across repositories, and the generated dispatch.
- [Manage Agent Integrations](https://greysquirr3l.github.io/entirely/guides/agent-integrations/): List, install and remove the agent integrations the Entire CLI supports, and see which ones receive the editor's own events.
- [Integrations and the MCP server](https://greysquirr3l.github.io/entirely/guides/integrations-and-mcp/): See which Entire plugins and the Entire MCP server are available per project, install or turn them on from the view, and add the server to .mcp.json.
- [Run and install plugins](https://greysquirr3l.github.io/entirely/guides/plugins/): Run an Entire plugin command from the editor, read its output, and install plugins from the plugin index.
- [Use the control plane](https://greysquirr3l.github.io/entirely/guides/control-plane/): Browse projects, repositories, organisations and clusters, and change them from the editor with confirmations that name the target and the login.
- [History import](https://greysquirr3l.github.io/entirely/guides/history-import/): Import existing agent history into Entire.
- [Blame and why this line](https://greysquirr3l.github.io/entirely/guides/blame-and-why/): Find which agent edit introduced a line, and why.
- [Diagnose problems](https://greysquirr3l.github.io/entirely/guides/doctor-and-diagnostics/): Produce a diagnostic report, read the CLI's own doctor findings, use the output channel, and fix the common causes.
