Entirely is an unofficial, community extension. It is not affiliated with or endorsed by Entire.

[Entire](https://entire.com) is a Git forge built for agent-human collaboration. It records what coding agents did as **sessions**, freezes them into **checkpoints**, and publishes that history so a team can see what every agent did and why. The Entire CLI does the work. Entirely is the editor-side surface for it.

## What you get

<CardGrid stagger>
  <Card title="A status bar that knows" icon="information">
    Shows whether the workspace is tracked by Entire and whether an agent session is live right now.
  </Card>
  <Card title="Sessions and checkpoints" icon="list-format">
    Every session Entire tracks for the repository, with the transcript in a read-only editor and each checkpoint opening straight into the native diff.
  </Card>
  <Card title="Trails and review" icon="approve-check">
    Approve, comment on, merge and check out Entire trails. Each action is confirmed, and each merge names what it merges.
  </Card>
  <Card title="Why this line" icon="magnifier">
    Select a line and see which agent edit introduced it, and why. File blame marks every line as attributed, recorded but not synced, or unattributed.
  </Card>
</CardGrid>

The extension never re-implements Entire. It discovers the installed CLI, reads its JSON output, and shells out for anything that changes state. If the CLI is missing, it shows a clear message with a link to the install instructions.
