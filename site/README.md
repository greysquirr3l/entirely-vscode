# Entirely documentation site

Astro + Starlight site for the Entirely extension, deployed to [greysquirr3l.github.io/entirely](https://greysquirr3l.github.io/entirely/). It is separate from the extension: its own `package.json` and `pnpm-lock.yaml`, excluded from the VSIX and from the extension's TypeScript and lint runs. Develop with `pnpm install` then `pnpm dev` (Node 22.23.4 or newer; pnpm is pinned in `packageManager`), and check with `pnpm check` and `pnpm build`. Pages live in `src/content/docs/`; each sidebar section autogenerates from its directory, ordered by `sidebar.order`, so adding a page needs no config change. The site is served under `/entirely`, so write links in Markdown with that prefix; images imported from `src/assets` are rewritten by Astro. Deploy with `pnpm run deploy` (or `pnpm run deploy:dry`, which stops before pushing): `scripts/deploy-docs.sh` builds, copies `dist/` into `entirely/` in the `greysquirr3l.github.io` clone, commits, pushes, and polls the live URL, reading its settings from the `deploy-docs` field of `package.json`. If the live URL returns "Site not found", Pages is enabled on the source repo and shadows the user page; run `gh api -X DELETE repos/greysquirr3l/entirely-vscode/pages` (reversible in Settings, Pages).

The screenshots under `src/assets` (`sessions.png`, `output.png`) are redacted copies with local paths covered. Retake them from a demo workspace whose path holds no personal name.
