# Entire CLI Discovery

> **Capability**: `cli-discovery` — behavioural contract the system must satisfy.

## Description

Locates the installed Entire CLI, verifies it can run, and reports its version - without ever blocking or crashing when it is absent.

## Requirements

- MUST locate the `entire` binary by checking PATH first, then the documented install locations, and MUST record which one was used.
- MUST distinguish 'not installed' from 'installed but broken' and MUST surface the distinction in the UI.
- MUST never throw out of discovery; a missing CLI is an expected state, not an error.

## Scenarios


### Scenario: cli-on-path

- **WHEN** the `entire` binary is on PATH and `entire version` exits zero
- **THEN** discovery reports the CLI as available with its version string

### Scenario: cli-absent

- **WHEN** no `entire` binary is found on PATH or in any known install location
- **THEN** discovery reports the CLI as absent and the extension shows an actionable install prompt instead of failing

### Scenario: cli-present-but-broken

- **WHEN** an `entire` binary is found but `entire version` exits non-zero or prints unparseable output
- **THEN** discovery reports the CLI as present but unusable, and the error detail is available for diagnosis
