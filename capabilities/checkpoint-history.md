# Checkpoint History

> **Capability**: `checkpoint-history` — behavioural contract the system must satisfy.

## Description

Lists the checkpoints recorded on the current branch and opens any checkpoint in the diff editor.

## Requirements

- MUST source checkpoints from `entire checkpoint list --json`.
- MUST open a checkpoint's diff using the native VS Code diff editor rather than a custom view.
- MUST tolerate a checkpoint whose diff is unavailable, showing an explanation instead of an error toast.

## Scenarios


### Scenario: list-checkpoints

- **WHEN** the user opens the checkpoint list in a tracked repository
- **THEN** each recorded checkpoint is listed with its message, author and time

### Scenario: open-checkpoint

- **WHEN** the user selects a checkpoint
- **THEN** the checkpoint's changes open in the diff editor

### Scenario: checkpoint-without-diff

- **WHEN** a checkpoint has no retrievable diff
- **THEN** the extension explains that the diff is unavailable and does not open an empty diff
