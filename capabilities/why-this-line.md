# Why Does This Line Exist

> **Capability**: `why-this-line` — behavioural contract the system must satisfy.

## Description

Answers, for the cursor's line, which agent edit introduced it and why.

## Requirements

- MUST use Entire's own `why` command to answer, so the answer matches the CLI and the web UI rather than re-deriving history locally.
- MUST present the answer with the originating session and checkpoint when the CLI supplies them.

## Scenarios


### Scenario: explain-line

- **WHEN** the user runs the why-this-line command with the cursor on a changed line
- **THEN** the originating agent, session and explanation are shown

### Scenario: unexplained-line

- **WHEN** Entire has no record of the line under the cursor
- **THEN** the extension says the line is not attributed to any recorded change
